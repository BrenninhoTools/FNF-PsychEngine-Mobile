# Psych Engine Mobile v1.0.4 - Patch v1.1

## New
- **FPS Rework** in Options > Graphics:
  - **Off**: uses the Framerate option, like before.
  - **Unlocked**: no framerate limit.
  - **Display**: matches your screen's refresh rate.
  - **Adaptive**: matches your screen and lowers the limit when the game can't keep up, so the framerate stays stable.
- The game drops to 30 FPS while in the background to save battery (when FPS Rework is on).
