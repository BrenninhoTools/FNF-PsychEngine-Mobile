# Psych Engine Mobile v1.0.4 - Patch v1

> This port is vibecoded (made with AI assistance). Please report bugs in the Issues tab.

## New
- **Haptics**: vibration on note hits, sustains, misses and menu touches, with a **Haptics Intensity** option (0.0 to 5.0).
- **Arrows** hitbox mode: bigger player arrows at the bottom and small opponent strums in the top-left corner.
- Drag to scroll in the pause menu.

## Changes
- Simpler default hitbox style, default opacity is now 20%.
- Smaller purple touch cursor.
- Full screen style no longer zooms the stage.
- Pause button is 60% visible, Freeplay back button is 30% visible, the pause menu has no back button.
- Mobile Options reorganized.

## Fixes and improvements
- Better touch input: second finger taps count, quicker swipes.
- Faster first launch: game files are copied from the app in parallel, with a free space check.

## Downloads
- **Android**: `PsychEngine-v1.0.4-patchv1-android.apk`
- **iOS**: `PsychEngine-v1.0.4-patchv1-ios.ipa` (unsigned, install with AltStore, SideStore or similar)
